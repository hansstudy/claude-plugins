# Claude Code plugins by Hans Study

A Claude Code plugin marketplace from [Hans Study](https://hans.study). It holds installable
plugin folders only; plugin folders are published from each tool's tagged release.

## Add the marketplace

```
/plugin marketplace add hansstudy/claude-plugins
/plugin install cisco-switch-config@hansstudy
```

## Plugins

| Plugin | Description | Source repository |
| --- | --- | --- |
| [cisco-switch-config](plugins/cisco-switch-config) | Audits Cisco IOS and IOS-XE switch running-configurations for security and reliability defects and generates hardened baseline configurations. Offline, Python standard library only. | [hansstudy/cisco-switch-config](https://github.com/hansstudy/cisco-switch-config) |
